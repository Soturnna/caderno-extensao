# Ficha da Chrome Web Store — Caderno de Soluções 1.0.0

## Aba "Ficha da loja"

**Descrição:**

O Caderno de Soluções reúne, em um painel lateral, as lições de fórmulas do time: Excel em português, medidas DAX do Power BI e consultas SQL.

Cada lição segue a mesma estrutura de aula:
• Problema: a situação real que exige a solução.
• Solução: a fórmula completa, com cores por tipo de elemento e botão Copiar.
• Decomposição: cada trecho da fórmula explicado em etapas numeradas.
• Por quê: a justificativa da escolha das funções.
• Atenção: as armadilhas e os casos de borda.

Recursos:
• Busca que ignora acentos: digite "maximoses" e encontre MÁXIMOSES.
• Filtros por linguagem: Excel, DAX e SQL.
• Abre ao lado da planilha, sem trocar de aba (atalho Alt+Shift+C).
• Funciona sem internet, com a última versão baixada das lições.
• Tema claro e escuro, de acordo com o sistema.
• Novas lições aparecem automaticamente, sem atualizar a extensão.

A extensão não coleta nenhum dado pessoal.

## Aba "Práticas de privacidade"

**Descrição de finalidade única:**
Exibir, em um painel lateral do navegador, lições de fórmulas de Excel, DAX e SQL com busca e cópia da fórmula.

**Justificativa — sidePanel:**
A interface inteira da extensão é um painel lateral, aberto ao lado da planilha para consultar as lições sem trocar de aba.

**Justificativa — storage:**
Guarda localmente uma cópia das lições, para o painel abrir instantaneamente e funcionar sem internet, e o filtro de linguagem escolhido pelo usuário.

**Justificativa — permissão de host (https://soturnna.github.io/*):**
Baixa o arquivo público de lições (licoes.json), publicado pelo próprio desenvolvedor no GitHub Pages. Nenhum dado do usuário é enviado.

**Código remoto:** Não, não estou usando código remoto. (O arquivo baixado contém apenas texto das lições, sem lógica executável.)

**Uso de dados:** não marcar nenhuma categoria de dados coletados.
Marcar as três declarações de conformidade:
• Não vendo ou transfiro dados do usuário para terceiros fora dos casos de uso aprovados.
• Não uso ou transfiro dados do usuário para fins não relacionados à finalidade única do item.
• Não uso ou transfiro dados do usuário para determinar a capacidade de crédito ou para fins de empréstimo.
